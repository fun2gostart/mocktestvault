DEFECTS FOUND AND FIXED
1. Scorecard submission threw a ReferenceError because `wrongPenalty` and `correctWeight` were referenced without declarations. This prevented the scorecard from completing.
2. Scorecard calculation/display now tracks marks earned from correct answers and actual negative penalties from question-specific marking configurations. The penalty tile is shown only when a negative penalty was incurred.
3. Mobile viewport overflow was found on the CBT chapter pages. The shared `css/test-engine.css` now has a compact mobile layout for the header, controls, test layout, action bar, and question palette.
4. Service-worker cache key incremented from `mtv-cbt-v47` to `mtv-cbt-v48` so updated shared CSS/JS are not hidden behind the previous cache.
