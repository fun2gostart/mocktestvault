2. RUNTIME QUESTION-ID COLLISION
- Two live-page configurations combine multiple question JSON pools in Random mode: JEE Main Speed Drill 01 and NEET UG Speed Drill 01.
- JEE page: 25 IDs collide across set 1 and set 2 with different question stems.
- NEET page: 45 IDs collide across set 1 and set 2 with different question stems. The 70 co-loaded collisions are listed in PHASE5_ACTIVE_QUESTION_ID_COLLISIONS_v2.9.13.csv.
- Root cause: persistent bookmark keys used page path + local question ID, while both pools restart numeric IDs at 1.
- Fix: updated getQuestionKey() to append a stable content fingerprint (stem + ordered options) on those two pages only. Other pages retain their existing bookmark key format. Question-bank JSON and scoring logic were not changed.
- Service-worker cache bumped from mtv-cbt-v48 to mtv-cbt-v49.
- Existing saved bookmarks on these two NTA pages use ambiguous legacy path+ID keys and cannot be safely assigned to one of two different questions. Previously saved bookmarks on these pages may need to be recreated; new bookmarks use the unique fingerprint keys.
