☁️ AWS Certified Cloud Practitioner (CLF-C02) Blueprint

Official Amazon Web Services Exam Guide: 65 Questions • 90 Minutes • Passing Benchmark: 700 / 1000 Scaled Points

1. Cloud Concepts (24% ~ 16 Qs) Cloud value proposition, CapEx vs OpEx, economies of scale, and the 6 Well-Architected Framework pillars.
2. Security & Compliance (30% ~ 20 Qs) Shared Responsibility Model, IAM roles & MFA, Security Groups vs NACLs, AWS WAF, Shield, KMS, and Artifact.
3. Cloud Technology & Services (34% ~ 22 Qs) Compute (EC2, Lambda, Fargate), Storage (S3, EBS, EFS), Databases (RDS, Aurora, DynamoDB), and VPC networking.
4. Billing, Pricing & Support (12% ~ 7 Qs) Cost Explorer, AWS Budgets, Pricing Calculator, Consolidated Billing, and the 4 AWS Support plans.
⚖️ Official Scoring & Passing Threshold: • Passing Score: 700 out of 1000 scaled points (~70% raw threshold).
• Zero Negative Marking: There is no penalty for guessing. Unanswered items receive zero points. Always select an answer for every question.
• Exam Strategy: Flag unfamiliar scenarios and complete rapid-fire recall questions first (Cloud Concepts and Billing) before tackling multi-clause architectural networking questions.
