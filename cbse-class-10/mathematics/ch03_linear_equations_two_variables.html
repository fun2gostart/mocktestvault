Detailed Solution Review

📘 CBSE Class 10 Mathematics (Algebra) — Chapter 3: Pair of Linear Equations in Two Variables Blueprint

Analysis of simultaneous linear equations a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0 using graphical methods, algebraic consistency conditions, substitution, and elimination techniques.

🎯 Unique Solution (Intersecting Lines) Condition: a₁/a₂ ≠ b₁/b₂. The system is consistent with exactly one unique point of intersection (x, y) satisfying both equations simultaneously.
♾️ Infinitely Many Solutions (Coincident Lines) Condition: a₁/a₂ = b₁/b₂ = c₁/c₂. The system is consistent and dependent, representing identical overlapping straight lines with infinite solution pairs.
🚫 No Solution (Parallel Lines) Condition: a₁/a₂ = b₁/b₂ ≠ c₁/c₂. The system is inconsistent, representing two strictly parallel non-intersecting lines with zero common points.
🛠️ Algebraic Solution Techniques Substitution method (express y in terms of x and substitute into second equation) and Elimination method (multiply equations by constants to cancel one variable).

📝 Illustrative Practice Questions & Worked Explanations

Q1 (Consistency: Unique Solution Condition): If the pair of linear equations a1*x + b1*y + c1 = 0 and a2*x + b2*y + c2 = 0 represents two lines that intersect at a single point, which algebraic condition must hold true?

  • (A) a1 / a2 = b1 / b2 = c1 / c2
  • (B) a1 / a2 = b1 / b2 != c1 / c2
  • (C) a1 * a2 = b1 * b2
  • (D) a1 / a2 != b1 / b2
🔍 View Correct Answer & Step-by-Step Marking Explanation

Correct Answer: Option (D) — a1 / a2 != b1 / b2

Explanation: For a system of two linear equations in two variables, a1*x + b1*y + c1 = 0 and a2*x + b2*y + c2 = 0, the two straight lines intersect at exactly one unique point if and only if their slopes are distinct. In algebraic coefficient form, this geometric condition corresponds to a1 / a2 != b1 / b2. When this inequality is satisfied, the system possesses a single unique solution (x, y) given by Cramer's rule, and the pair of equations is classified as mathematically consistent and independent.

Topic reference (not item-level provenance): NCERT Class 10 Mathematics, Chapter 3, Table 3.4

Q2 (Inconsistency: Parallel Lines Condition): A pair of linear equations in two variables has NO solution if their graph consists of two parallel lines. What is the algebraic ratio condition for this case?

  • (A) a1 / a2 != b1 / b2
  • (B) a1 / a2 = b1 / b2 != c1 / c2
  • (C) a1 / a2 = b1 / b2 = c1 / c2
  • (D) a1 * b2 + a2 * b1 = 0
🔍 View Correct Answer & Step-by-Step Marking Explanation

Correct Answer: Option (B) — a1 / a2 = b1 / b2 != c1 / c2

Explanation: A pair of linear equations in two variables has NO solution if their geometric graphs represent two distinct parallel straight lines that never intersect, no matter how far they are extended in either direction. Algebraically, this occurs when the lines share identical slopes but possess different y-intercepts, yielding the ratio condition: a1 / a2 = b1 / b2 != c1 / c2. Because there is no common coordinate pair (x, y) satisfying both equations simultaneously, the system is termed inconsistent.

Topic reference (not item-level provenance): NCERT Class 10 Mathematics, Chapter 3, Table 3.4
